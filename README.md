# ARVEN Residences — cinematic scroll real-estate site
Static HTML/CSS/JS. No build step. Open the folder in VS Code -> right-click index.html -> Open with Live Server (Ctrl+F5 if cached).

- `assets/frames/` — 240 WebP frames: f000–f119 = construction video, f120–f239 = interior video (joined at the finished building, so no cut).
- Scroll text chapters: `index.html` (`.chap` blocks, data-s/data-e = scroll range 0–1).
- Brand name, copy, WhatsApp number: edit `index.html` and `CONFIG` at top of `script.js`.
